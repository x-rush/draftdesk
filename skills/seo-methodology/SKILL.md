# 哥飞 SEO 方法论判定引擎

> 单一判定依据。任何关键词/需求/应用创意的价值判断，**必须走本决策树，禁止凭感觉**。
> 数据来源约定：哥飞 API 数据（gepheiFetchedAt ≤90 天）为权威源 ●；自采数据为补充 ○；两者皆无时降级判定并标「价值未验证」。

## 输入

$ARGUMENTS（要判断的词/需求/创意，可附带已有指标）

## 决策树（按序执行，任一终止条件命中即出结论）

### 第 0 关 红线（一票否决）
- 品牌/公司/人名/活动名 → **弃**（做=钓鱼站）
- 四禁忌相关（不出镜/私域/囤货/账号交易）→ **弃**
- 已被哥飞公众号公开解析过的词 → 竞争已明牌，默认弃（除非有明显新角度）

### 第 1 关 需求语义（triage 级）
- 有工具/产品/学习需求语义？无 → 弃。⚠️「纯资讯八卦→弃」仅指影视明星/综艺/体育类
  纯八卦；**AI 资讯判 strong 保留**（模型发布、AI 公司动态、AI 政策版权均为强需求）。
  且本关只作用于**站群词库选址**（siteCandidate 池），不作用于内容选题线
  （热点→簇→大纲→多平台，资讯是内容线的正当题材）。
- 搜索意图：tool 类加分（generator/converter/calculator/checker/tracker 词根族）；info 类中性；nav 类看是否可替代源站

### 第 2 关 量级与竞争（有数据用数据，无数据用降级口径）
有哥飞三指标（●新鲜）：
- 月搜 <300 → 弃；KD >29 且非新词 → 弃；CPC <$0.1 → 降级（商业价值弱）
- 新词豁免：趋势上升明显的 AI 新需求词，KD 高也做（前 10 都是弱鸡）
无三指标（降级口径）：
- strong + SERP 无垄断（sd≤1）→ 候选，标「价值未验证」
- 查 SERP 前 10：内页为主=可打；首页大站（时代周刊级）=弃

### 第 3 关 外链 ROI
估算进前 10 所需外链域 ≈ KD × 2.5，进前三 ≈ ×4
月流量 ÷ 所需外链数 = 单位回报；回报过低且有同等流量低成本词 → 换词

### 第 4 关 时间验证（宁缺毋滥）
- observations ≥5 天且持续在池 → 可信度高，配得上查三指标
- 首次出现时间：查是否新词（新词走豁免通道）
- 季节性验证：Google Trends 曲线平稳 vs 季节尖峰

### 结论输出格式
```
判定：做 / 不做 / 练手 / 观察
依据：第 X 关命中（引用具体指标与阈值）
缺口：缺什么数据（如有）
哥飞方法论出处：小课堂第 N 篇 / knowledge_ask 查询结果
```

## 数据源优先级
1. 哥飞 API（●，gepheiFetchedAt 90 天内）
2. 手动回传（✋manualAt，老大亲验，权重等同哥飞）
3. 自采探针（○，60 天 stale 即降权）

## 知识库深查（8 分/次，判定拿不准时用）
`knowledge_ask "具体问题"`——一次调用带出处与日期，不拆多次检索。
配额约束：仅在「第 2-4 关无法裁决」时使用；每月查询次数计入成本汇报。

## 与工作台的同源关系
本决策树 = 《选题标准与画像》§3.5 的 skill 化。工作台内置 AI 判定 prompt（termPolicy/intentPolicy/siteGate）与本树同源；发现冲突时以本树为准并回报修正画像。

## 消费画像（内置 AI 与外部 Agent 共用的消费侧口径）
- 选题消费：簇 → 至少一个具体写作角度（能写出「读者能带走什么」）才出选题
- 机会消费：应用创意按 form（web/app/miniprogram/tool）分模板；site 类必附三指标+竞品档案
- 遗弃消费：off 词归档不删除（archivedReason 必写）；weak 词保留观察
