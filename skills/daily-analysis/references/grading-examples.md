# 判级示例（真实脱敏样本）

判级三档的边界用例。立场：受众是 AI 工具向的个人创作者与职场人——先回答「这会改变读者明天做什么」。

## strong（三例）

### 例 1：多源交叉 + 明确变化
> 组标题：主流编程助手全面开放 Agent 编排能力
> 理由：三家厂商同周发布公告（GitHub/HN/官方博客三源交叉），个人免费档即可用；直接改变「多步任务怎么交给 AI」的工作流设计——创作者可产出迁移教程与编排模板类选题。

要素：**多源交叉 + 个人可用性明确 + 读者任务改变**。

### 例 2：数据支撑 + 连续事件
> 组标题：某平台创作者分成比例调整（第三轮）
> 理由：官方政策页连续第三个月调整，本轮附分成计算器更新；直接改变读者「在哪发、怎么定价」的决策。前两轮已有组（事件线挂接），本轮按新进展出增量选题，不重炒旧闻。

要素：**事件连续性（挂既有线）+ 决策影响 + 新进展**。

### 例 3：单一来源但具体可执行
> 组标题：某工具开放 API 的 rate limit 上调
> 理由：官方 changelog 单源但内容具体（数字前后对比明确），影响所有基于该 API 的自动化教程可行性——strong 的关键是「变化具体到能写进教程的更新点」。

要素：**变化具体可核对**弥补了单源。

## potential（观察池语义）

> 组标题：传某大厂内测新功能
> 理由：科技媒体转述「知情人士」，无官方确认、无可用范围——方向与受众相关但信息不足。挂池观察：官方确认或开放内测申请时升 strong。

potential 不是「不重要的 strong」，是**等一个确认信号**。reason 里写清楚升级条件。

## none（噪音判定）

> 组标题：明星离婚热搜 / 国际体育赛事 / 通用百科词搜索
> 理由：与 AI 创作无交集，无任何转化角度——归档（不占名额、可恢复）。

误判方向警示：不要因为「热度极高」把纯娱乐判 potential——判级看受众相关性，不看榜单位次。
