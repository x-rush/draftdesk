# 四平台官方活动采集与分析

1. 在自己的 Chrome / Edge 登录四个平台的创作者中心。Codex 内置浏览器与 Chrome / Edge 不共享登录状态。
2. 下载 `activity-collector.zip` 并解压，在浏览器扩展管理页开启开发者模式、加载已解压的扩展。安装过旧版的请重新解压下载包并在扩展页点「重新加载」，当前扩展版本为 1.4.0。
3. 在创作者中心首页或其他官方页面打开扩展，输入目标关键词与扫描页数，点击「打开活动页并采集」；扩展会先导航到该平台官方活动中心，等待列表加载，再启动采集。已经在活动页时按钮直接显示「采集当前活动页」。从其他网站打开扩展时可用下方四个平台入口先打开官方活动页。默认关键词涵盖 AI、AIGC、AI 视频、Vibe Coding 与 AI 编程。四平台各执行一次；扩展按平台保存本次采集，切到对应平台标签页可分别导出，不会被另一个平台的运行结果覆盖。抖音目前只读取当前显示月份。
4. 扩展为每个平台导出一份批量 JSON；返回工作台后可同时选择最多四份文件合并预览。预览会同时显示可分析、已过期、缺截止年份、只有摘要或不匹配关键词的线索，并保留官方来源地址。单次研究最多接收 24 条合格活动和 8 个目标关键词，超过时须缩小范围或分批导入，不会静默截断。点击「导入合格活动并运行 AI 分析」后，关键词会随本次任务进入 AI 策略，不改变保存的默认策略。

扩展对命中目标关键词的线索尝试读取可见详情，不点击报名、领取或发布按钮。无可核实截止日期、已过期以及只有摘要的活动不进入付费模型分析。页面只给出月日且没有明确年份时不会猜测年份；即使页面展示在活动中心，也只能作为待核线索。跨年或平台延长时间需要人工查看规则。小红书侧栏中的官方规则 iframe 若可读取，会连同详情保存；只有短简介时仍标记为摘要。抖音日历弹窗若包含完整规则和可核对日期，可进入分析，但因为没有单条活动链接，产物仍需按标题到官方活动中心复核，不会直接成为通过审稿的推荐。页面变动、登录过期和验证会产生错误或缺项，不能以 0 条解释为没有活动。

## 采集路径与当前边界

| 平台 | 已核对的列表结构 | 详情与日期处理 | 翻页范围 |
| --- | --- | --- | --- |
| B 站 | 已登录页面中的 `h2 a[href*="/blackboard/era/"]` 和 `.event_status`；列表是客户端渲染，不能直接 `fetch` 页面 HTML 当作列表 | 在官方活动详情页读取规则；年份来自列表日期 | 点击 `.flip-left .next-page`，最多 5 页 |
| 小红书 | `/new/events` 的 `.card-box`、`.title`、`.desc`、`.time` | 打开详情侧栏，读取可访问的官方 `fe.xiaohongshu.com/ditto/vincent/` 规则 iframe；日期仍以规则原文为准，读取失败时只留摘要 | `.d-pagination-page-content`，最多 5 页 |
| 抖音 | 创作者中心活动日历的活动条目 | 读取活动弹窗；当前显示月份的年份来自日历标题；没有单条链接时保存活动中心 URL 和标题，结果须复核 | 当前月份；需要用户切换月份后再执行 |
| 快手 | 创作者中心活动列表卡片 | 只尝试打开活动标题关联的详情，不点「去领取」；拿不到官方详情时只作摘要 | 当前列表向下滚动，最多 5 屏 |

每个平台最多保留 100 条线索，分析前由工作台再次按截止时间、规则完整度及用户关键词过滤。扩展导出的 JSON 保存在用户本机；浏览器运行期间需保持官方页面登录状态，验证码或页面结构变化需要人工处理。手动导入单条规则时，工作台要求填写从正文核对的投稿截止日期，已过期或原文不含该年份与日期时不会启动付费分析。

扩展通过 Chrome / Edge 当前已登录页面工作，不读取 Cookie，不上传平台账号资料。导出的活动规则在提交分析时会发送给用户自行配置的模型供应商。数据导入和运行仍由用户确认；这不是无人值守的服务器定时采集。来源代码在 `public/activity-collector`，打包文件是 `public/activity-collector.zip`。

2026-09-25 在内置浏览器复核了四个平台的已登录页面。B 站活动列表是客户端渲染；小红书活动列表使用 `.card-box`；抖音当前月份可见 `.douyin-creator-common-calendar-event-item`，点击后显示含活动时间、玩法和奖励的 `[role="dialog"]` 侧栏；快手活动卡片使用 `.list_item`，含标题、简介与月日时间。快手列表没有明确年份，必须在详情补到年份；抖音没有单条活动链接，产物须按标题复核。扩展在用户 Chrome / Edge 的四平台端到端操作、快手详情新标签捕获、抖音跨月和登录失效恢复仍需实测；不能宣称四个平台稳定全量采集。
