# 四平台官方活动采集与分析

1. 在 DraftDesk「创作活动」打开平台官方入口，并在自己的 Chrome / Edge 登录。Codex 内置浏览器与 Chrome / Edge 不共享登录状态。
2. 下载 `activity-collector.zip` 并解压，在浏览器扩展管理页开启开发者模式、加载已解压的扩展。旧版需重新加载。
3. 在官方活动中心打开扩展，输入目标关键词与扫描页数，点「自动采集当前平台」。默认关键词涵盖 AI、AIGC、AI 视频、Vibe Coding 与 AI 编程。四平台各执行一次；抖音目前只读取当前显示月份。
4. 扩展导出批量 JSON；返回工作台导入。预览会显示可分析、已过期、缺截止日期、只有摘要或不匹配关键词等状态。点击「导入合格活动并运行 AI 分析」后，关键词会随本次任务进入 AI 策略，不改变保存的默认策略。

扩展逐条读取可见详情，不点击报名、领取或发布按钮。无可核实截止日期、已过期以及只有摘要的活动不进入付费模型分析。页面只给出月日时按当前日历年份推定，导出包会提醒核对；跨年或平台延长时间需要人工查看规则。小红书活动侧栏常仅有简介，扩展会标记为摘要，须补充官方规则后再分析。页面变动、登录过期和验证会产生错误或缺项，不能以 0 条解释为没有活动。

扩展通过 Chrome / Edge 当前已登录页面工作，不读取 Cookie，不上传平台账号资料。导出的活动规则在提交分析时会发送给用户自行配置的模型供应商。数据导入和运行仍由用户确认；这不是无人值守的服务器定时采集。来源代码在 `public/activity-collector`，打包文件是 `public/activity-collector.zip`。
