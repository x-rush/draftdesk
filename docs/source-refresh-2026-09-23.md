# 个人研究来源优化与真实复测（2026-09-23）

## 范围

本轮只做来源/策略优化和真实小样本验证。不代表全站重新验收，也不代表多日稳定性验收。全部产物保持私有，定时策略未开启。微信公众号文章尚未撰写或发布。

## 已实现并部署的改动

- 新增 OpenAI 与 Google AI 官方 RSS、Simon Willison 实践文章、V2EX 技术讨论。实际探测均成功解析，分别返回 100、20、15、50 条；数量只是 feed 内容量，不是有效推荐量。
- 增加内容筛选词，作用于标题与正文，命中任意词才保留；英文短词按词边界匹配，避免 AI 匹配无关英文单词。关键词负责检索，筛选词负责过滤，两者独立。
- RSS 优先读取 content:encoded/content，避免明明有正文却只把短摘要送入模型。
- 资讯优先具体产品更新；应用机会优先社区中的实际问题。官方来源可配置精确关联域名，帮助把帮助中心与产品文档正确分类；官方分类不等于结论已核实。
- 修复证据整理返回错误 ID 时直接失败的问题：引用 ID 校验进入结构化响应校验，可触发既有一次修复；不会接纳无效 ID。
- 热词策略新增“只分析原始指标”，无指标时保留线索并零调用结束。此门槛不能凭空获得任意关键词指数；有单点指标仍不等于存在增长趋势。
- 界面提供筛选词、指标门槛、关联官网域名，并在运行前展示计划。

## 当前个人策略

资讯：来源库提供 OpenAI/Google 官方更新、AIHOT 线索与 Tavily 补证；围绕文档、会议、表格、字幕和创作者工作流。复测限定相关厂商域名，减少社交转载；域名限制也适用于 RSS 的文章链接，因此当前策略会过滤 AIHOT 聚合站链接。该限定适合本轮的 ChatGPT/Gemini 方向，不是覆盖所有国产 AI 工具的通用白名单；需要聚合线索时应显式加入其域名或清空白名单。

机会：V2EX 公开问题 + 产品动态 + 网页搜索，找字幕纠错、会议待办核对、文档整理。产品动态只能提供竞品/替代品线索。一次额外的 V2EX/知乎/少数派定向搜索返回零条，未作为成功采集；不靠放宽证据标准凑结果。

趋势：Google Trends 美国热榜 + Web，要求原始指标。美国地区热榜不能当作中国需求，也不是 ChatGPT/NotebookLM 任意词历史指数接口。本轮没有获得对应指标，系统应明确零推荐。

Simon 来源已可选，但本轮三个主任务没有使用它生成结果。人物研究本轮未复测。

## 后续：资讯缺 details 的针对性修复

针对上述单次评测失败，editorial-research 更新为 1.3.1：明确每条 news 必须独立提供完整 details，即使摘要已表达相同信息也不能省略；未知范围写“本轮未核实”，不能扩大为“官方未披露”。修复提示遇到 details 错误时强调按 kind 重建字段、只整理已有证据、不用空值或编造事实补齐。评测脚本新增具体错误路径，避免只显示未通过而无法定位原因。

新增模拟响应回归覆盖缺字段后成功修复和连续缺失后拒绝两条路径；这验证程序处理行为，不代表真实模型首轮合格率提高。该补丁未进行额外付费模型复测，也未更改此前对照评分。
