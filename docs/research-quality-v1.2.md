# 研究质量 1.2 实现与验收

## 实现

1. 资讯/应用/趋势/人物采用不同检索意图；证据按对应来源偏好排序并跨来源轮流选取。尊重用户域名和排除词，不绕过配置。网页初搜预留最多两次原有查询额度用于缺口补证，同时预留有限证据位置。
2. 证据整理阶段提出具体缺口，后续最多两次 Tavily basic 查询；补证失败同样计次数，所有调用共用 maxQueries。检索到候选不代表核实成功。未补上问题写入 unknowns。没有启用 web 来源、密钥或剩余额度时保留未知。
3. 审稿 reject 持久化为 rejected；兼容旧版 issue 中的 reject。默认列表只显示推荐和待验证。被拒绝内容不能公开；手动编辑后回到待验证。正常无证据、无有效聚类、空分析结果和相同策略的重复资料都能正常完成为 no-findings；来源异常仍失败。
4. 每条指标保留原文、单位、地域、来源、周期和观察时间。相同周期重复采集或纠错仍是一个观测。只有精确数值、明确 cadence 和有效日期可比较，day/week 必须相邻；零基数、分桶、不同地域、未知周期不算百分比。累计 Stars 变化明确不是需求增长。
5. 同 URL、相同规范化标题或长文本高度重合归入事件。保留 new/update/duplicate 修订与证据引用，不删除原资料。相同策略和目标中已完成研究的重复材料不重复付费分析；策略目标或关键词变化允许重新研究。更新仍需审稿，文本差异不代表事实已确认。详情可看到同事件其他研究标题。
6. 保存优化前六项研究 Skill 基线，当前版本 1.2.0。固定材料、模型和输出上限的 A/B 记录引用诊断、token、耗时，五维人工盲审缺失时总分为 null。记录不进入正常选题库。

## 边界

这是一轮工程能力实现，不是内容质量提升的统计证明。当前每日预留 991769，高于恢复后的 600000 上限，本轮没有执行新付费模型调用，也未提高限额或开启计划。搜索策略效果、补证召回率与语义评分需在有预算时用固定案例实测。

现有材料回填得到 64 个事件、7 个指标快照；没有伪造第二期数据。事件匹配保守，不能识别所有语义改写；未知采样周期不会强行计算增速。未新增国内平台原生热榜。Tavily basic 返回的摘要不冒充完整网页或官方认证。

## 验证
