# 工作台浏览与创作体验

- 每日发现、选题库、趋势、应用、人物、运行记录与收件箱每页 20 条。服务端先筛选再分页。
- 网址保留视图、关键词、类型、质量、创作进度、页码与任务筛选。刷新恢复；同一标签页使用 sessionStorage 保留滚动位置。关闭详情保留列表位置。
- 详情的上一条／下一条遵循当前筛选顺序，可以跨页。Esc 关闭。
- 创作进度：待挑选、准备写、写作中、已发布。修改进度自动加入选题库；与研究质量和公开权限独立，不触发发布。老数据默认待挑选。
- 讨论显示关联材料、读者和证据数量。历史讨论会重新读取关联内容。整理草稿可预览；同类型支持保存新内容或更新原内容，更新展示字段差异并检查 revision 冲突。更新保留原创作进度，研究质量回到待验证。
- 页面打开时轮询任务状态，完成／失败／取消有提示；完成可按任务筛选结果，失败可直达对应运行说明。运行记录也保留结果入口。此功能是站内提示，不是系统推送；关闭页面期间的记录可从运行记录查阅。
