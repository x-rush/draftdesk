## 结论与方法

## 已修复

1. 模型按任务使用专用 JSON Schema，禁止错类型和超数量，引用 ID 验证进入结构修复阶段。
2. 将明确的字段路径和校验原因提供给修复调用，保留诊断，避免同一句泛化报错无限重试。
3. 排除理由的缺省 evidenceIds 规范化为空数组，产物的必需证据约束不放宽。
4. Qwen 思考预算设定上限，审稿输出设为 5000；超时和未回传用量明确提示可能计费。
5. 检测同稿转载以及平台文案内的虚构第一人称实测，复核历史产物。
6. worker 以 Node 直接启动并配置退出宽限，讨论和整理任务续租，防止长调用锁过期。
7. 模型和搜索分别测试；失败任务可以保留证据重试；讨论支持安全 Markdown 渲染。
8. SearXNG 插件与环境变量接通，提交 Skill 补充合法枚举和错误诊断，提供 Hermes 可信提交适配器。
