# 热榜与产品线索来源

本表只写入从本机 Docker 环境验证过的入口。来源可读不等于每条都与 AI 相关；研究策略会按用户关键词、排除词、时间窗口和地域再过滤，未命中允许零结果。热榜是平台内关注信号，不能直接推断市场需求。

| 来源 | 类型 | 状态与用法 |
| --- | --- | --- |
| 百度热搜 | 中国搜索热榜 | 默认启用；读取官方实时榜。指数为百度平台口径，即时快照不计算增长率。 |
| 微博热搜 | 中国社交热榜 | 可选但默认停用；匿名访问返回访客验证时明确报错，不绕过验证。 |
| Google Trends 美国、英国、日本、台湾地区、印度、韩国、德国 | 地域搜索热榜 | 各地区 RSS 在 Docker 中已验证；策略按地域选用，不合并不同地区指标。中国大陆 `geo=CN` 本轮返回 HTTP 400，未加入。 |
| GitHub Trending | 全球开发者热门仓库 | 官方页面已验证；解析仓库链接、简介和当日新增 Stars。Stars 不等于用户付费意愿。 |
| Hacker News Top | 全球技术社区热门讨论 | 官方 Firebase API 已验证；最多取前 30 条，记录讨论链接和榜单分数。分数不是搜索量。 |
| Product Hunt Feed | 全球新产品线索 | 官方 Atom Feed 已验证；属于近期产品发布，不宣称是站内热榜排名，供应用机会策略选择。 |
| B站热门榜 | 国内视频热门 | 官方域名接口本轮有时返回 `code=-352` 或超时，未作为稳定内置来源。 |
| 知乎 / 抖音 / Reddit 官方直连 | 热榜候选 | 本轮分别遇到 403、验证空壳或 429；知乎和抖音改用下述聚合补充，Reddit 未接入。 |

## 本地聚合补充

`docker compose up -d` 会启动仅供工作台容器访问的 DailyHotApi（不暴露宿主机端口）。代码来源为 [imsyy/DailyHotApi](https://github.com/imsyy/DailyHotApi)，容器固定镜像摘要以便复现。聚合器仍访问各平台公开入口，不具备绕过登录或保证持续可用的能力；其代码许可不代表平台内容的转载或商业使用授权。

本机实际试跑：知乎、抖音、今日头条、百度贴吧、稀土掘金返回结构化榜单；B站首次上游请求超时、复测返回 50 条，因此出于稳定性考虑仍默认停用。微博和快手返回解析错误，默认停用。聚合器的百度路由返回无效词条，工作台继续只用百度官方页面，不启用该路由。平台可达性会随时间和网络变化，不将一次试跑写成长期可用保证。

聚合条目只保存标题、原平台链接、榜单更新时间与同平台热度。工作台验证链接确属对应平台、榜单更新时间不超过 2 小时；无效链接、空榜、过期榜会直接报来源异常。数据源列表可逐个点「检测连接」，仅测试榜单，不调用模型或写入证据。研究结果显示“聚合补充”及实际更新时间。研究策略仍用用户关键词筛选，未命中允许零结果；热点标题不是新闻事实、创作者活动详情或增长率证据。重要结论要再查原文与一手来源。已有用户的策略勾选不被迁移覆盖，可在「搜索源」与「研究策略」自行启用所需平台。

默认热词策略继续优先百度与美国 Google Trends；其他已验证来源在「搜索源」目录中可用，用户可按创作受众勾选。添加来源不意味着扩大每次模型调用预算，工作台仍执行单任务证据与模型上限。新用户会得到完整来源目录；已有用户的策略选择保持不变。
