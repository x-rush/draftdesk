本次分数只代表这一天的样本：8 分表示主要流程实测可日常使用；6 分表示能用但需要明显人工判断；4 分表示基础能力存在，尚未实现承诺的价值。自动化测试通过不自动提高内容质量分数，也不等于四平台或长期定时运行成功。

## 实际检查范围

- Docker 的 app、worker、dailyhot 均在运行；app 健康检查通过，首页、工作区、公开页、外部数据合同接口返回 200。生产构建、TypeScript 检查和 103 项自动化测试通过。
- 用浏览器在 1440px 桌面与 390px 手机视口检查全部 14 个工作台视图，均未出现页面级横向溢出或 JavaScript 页面异常；另验证菜单、筛选、分页和任务入口的交互。截图在忽略的 `data/layout-*.png`，不随仓库发布。
- 实测已启用的掘金、贴吧、头条、抖音、知乎热榜连接；Tavily 搜索和百炼模型连接测试通过。来源预览返回原始线索，部分官方源本轮没有命中，不能解释为来源长期稳定。
- 使用保留的 10 条热词证据实测研究：原流程因最大 token 的保守预留耗尽而失败；修复结算后，同一批证据以 3 次模型调用、38,760 个已回传 token 完成，产出 2 条待验证热词，无通过检查的推荐。一个事件的补证问题曾混入另一产物，已修改为按证据范围关联并加回归测试。完成后的重复重试被同事件去重为“无新增”，没有再次收费，故该关联修复的生产效果仍待下一批新证据确认。
- 对其中一条热词进行两次真实 AI 讨论，并完成一次“讨论整理为选题预览”：讨论持久化、模型回复和单条草稿生成成功，草稿仍带 3 项证据缺口。第一次讨论自设数值门槛并确认了仅有标题的产品归属；Skill 已收紧。第二次不再确认归属，但仍给出带数字的短期观察假设；再次收紧后尚未做第三轮真实调用。
- 外部收件协议、令牌权限、幂等、草稿引用、预算、定时幂等、隐私门槛、活动日期与适配器 DOM 等由自动化测试覆盖。OpenClaw / Hermes 的真实小样本接入记录见 [Agent 实测](agent-live-evaluation-2026-09-24.md)，不代表连续稳定性。

## 下一步达到 8 分需要的证据

1. 使用真实官方正文、用户问题原话及同口径历史指标各完成多批资讯、机会和热词研究；记录推荐的引用准确率、可执行性、人工通过率和每条成本。没有合格材料时允许无推荐。
2. 在用户自己的 Chrome / Edge 登录四个平台，逐个对照活动列表、详情、日期、原始链接和导入结果，记录缺页、登录失效及页面变动；当前浏览器控制接口返回 `nodeRepl.fetch request failed`，本轮无法代替该端到端验收。
3. 连续观察至少几个自然日的计划触发、来源成功率、模型用量和失败恢复，再评价稳定性；单次手动成功不算长期运行。
